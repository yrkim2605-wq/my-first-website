# 덕명눈솔(MITUTOYOSQUARE) 사이트 분석

레퍼런스: https://mitutoyosquare.com/shop/ (분석일 2026-10-29)

## 성격
- 미쓰도요 공식 대리점의 측정기·공구 B2B 쇼핑몰, 정보 중심, 38년 경력과 공식 대리점 신뢰 강조
- 색상·폰트는 마크업만으로 확인 불가 → CSS 확인 필요

## 구조
- 상단 바: 쇼핑몰, DMNS B2B, 회원가입, 로그인, 장바구니, 온라인견적, 주문/배송조회, 쿠폰존, 개인결제, 사용후기, FAQ, 1:1문의
- 헤더: 로고, 검색창, K-9 카탈로그, 온라인견적, 장바구니, 카카오톡 채널
- GNB: 카테고리(아이콘 약 22개), 온라인견적, 카탈로그, 의뢰/요청(견적·AS/교육·검교정·샘플측정·데모), 고객센터, 기술자료
- 우측 플로팅 메뉴: 장바구니, 온라인견적함, 주문/배송, 오늘본상품, 브랜드 바로가기

## 메인 섹션 순서
1. 팝업 → 2. 헤더/GNB → 3. 배너 슬라이더(3장) → 4. 명패 → 5. PROMOTION(상품 4개 + 카테고리 타일) → 6. 추천상품 → 7. 최신상품 → 8. 회사 소개 → 9. 브랜드별 이미지(MITUTOYO, DORMER, SHS, SK, KANETEC, TOHNICHI) → 10. 푸터

## 상품 카드
- 정사각 썸네일, 뱃지(히트·추천·NEW·할인·재고문의), 상품명, 가격(₩, 할인 시 정가+할인가), 고가 장비는 "가격문의 1644-9879"
- 장바구니/구매 버튼이 카드에 없음

## 상품군
- 측정기: 삼차원측정기, 형상측정기, 투영기, 공구현미경, 리니어하이트, 경도계, 표면조도·진원도
- 측정공구: 캘리퍼스, 마이크로미터, 보어게이지, 인디게이터
- 게이지/공구: SHS 링·플러그, SK 핀, 돌머(탭·드릴), 토니치(토크렌치), 가네텍(자석)
- 부품: 카운터, 인터페이스 유닛, 배터리

## 푸터

# 포트폴리오 1단계 검증 기록 (2026-10-16)

범위: 찜하기 실제 구현 · 혜택 배너 문구 · 색상 대비(WCAG AA 4.5:1) · 시험 환경 정리.
서버(Supabase)는 바꾸지 않았고 main 병합 · push · 배포는 하지 않았어요.

## 바뀐 것
- **찜하기**: 카드 · 상세 · 마이페이지가 같은 목록을 써요. 이 브라우저(localStorage)에만 저장해요 (전용 키 `my-bakery-review:v1:bookmarks`, 로컬 모드 `local` / 계정 모드 `account:<사용자 id 또는 guest>`로 분리). 리뷰 · EXP · 도감 · 퀘스트 저장값은 건드리지 않아요.
- **배너**: "모험 일지를 남기면 EXP가 쌓이고, 퀘스트 · 배지로 레벨업해요" (로그인하면 "내 모험가 보기 →"). 글자와 화살표가 한 덩어리라 좁은 화면(320 · 360 · 390px)에서도 화살표가 홀로 남지 않아요.
- **색상**: `terracotta.dark #9A3B2A`(라벨 글자 · NEW 칩), `secondary.dark #46593A`, `gold.text #6F4E0F`(보상창 · 퀘스트 보드 금색 글자), `error.main #A82A24`(삭제 · 오류 빨강), 세이지 블록 위 글자는 진한 갈색(`SectionHeading tone="onSage"`), 푸터 저작권 투명도 0.8, 캐러셀 옆 카드는 사진만 흐리게. 장식용 `terracotta.main` · `gold.dark`는 글자에 쓰지 않아요.
- **시험**: `review-load-ui` · `bakery-rating` 렌더링 환경에 `BookmarksProvider` 추가, `ranking-repository`의 낡은 기대값 교체(478df91에서 이용자 문구를 기술 용어 없는 안내로 바꾼 것이 의도 — 합격 기준은 "코드 NOT_SET_UP + 준비 중/다시 시도/문의처 안내 + 기술 용어 없음"으로 유지), 새 시험 `bookmarks`(31) · `color-contrast`(17).

## ⚠️ 시험에서만 쓴 우회 — 실제 배포 환경 검증 필요
- 카카오 JS 키는 `localhost:5173`과 배포 주소(`yrkim2605-wq.github.io`)에서만 허용돼요. 로컬 모드(5199 포트) 시험에서는 **시험 도구(playwright)가 카카오 요청의 Referer · Origin · KA 헤더를 5173으로 바꿔서 전달**했어요. 앱 코드에는 이 우회가 없어요.
- 그래서 **배포된 github.io 주소에서 실제 카카오 목록 · 지도 · 찜 · 리뷰 흐름은 아직 확인하지 않았어요.** 배포 전후에 직접 확인이 필요해요.

# 빵집 평균 별점 · 리뷰 개수 (계정 모드)

> 상태: 원인 확인 + 수정 + 자동 검증 완료 / **실제 브라우저에서의 화면 확인은 사용자 작업 필요**
> 서버(DB) 변경 없음 · 새 마이그레이션 없음 (0005의 `ranking_bakeries` 뷰를 읽어요). 기존 리뷰 · EXP · RLS는 건드리지 않았어요.

## 1. 원인 — DB 집계가 아니라 화면이었어요

| 확인한 것 | 결과 |
|---|---|
| 리뷰 저장 시 `rating`이 `reviews` 표에 저장되는가 | ✅ 실서버 확인: 입력한 별점이 그대로 저장됨 (옵스 해운대점 5점, 이흥용과자점 4점 — 수정한 값도 반영) |
| 서버의 빵집별 평균 · 개수 집계 | ✅ 정상 (`ranking_bakeries`: 평균 5.0/1개, 4.0/1개 — `reviews`를 직접 계산한 값과 일치) |
| 화면이 그 값을 읽는가 | ❌ **읽지 않았어요.** 실제 빵집의 `rating`을 `BusanBakeriesContext`에서 **항상 0으로** 만들고 있었고, 상세 · 카드 · 지도 카드가 모두 그 `0`을 보여줬어요 (그래서 항상 “아직 별점이 없어요”). 목록의 리뷰 개수도 예시 데이터 표에서 읽고 있었어요 |
| 갱신 타이밍 문제인가 | 아니에요. 계산 자체가 화면에 없었어요 |

## 2. 수정 내용

- **한 곳에서 계산**: `useBakeryRatings()` hook이 서버 집계를 한 번 불러와서, **상세 · 목록 카드 · 지도 미리보기 카드가 같은 숫자**를 써요. (`ReviewsContext`가 리뷰와 함께 평균 별점 집계를 불러와요)
- **즉시 갱신**: 리뷰를 쓰고 · 고치고 · 지운 직후 `ReviewsContext`가 다시 불러오면서 별점 집계도 함께 갱신돼요. 빵집 상세를 열 때마다도 서버의 최신 리뷰 · 집계를 다시 불러와서 **다른 사용자가 남긴 리뷰**도 반영돼요.
- **표시 규칙**
  | 상황 | 상세 | 목록 카드 | 지도 카드 |
  |---|---|---|---|
  | 리뷰 있음 | ★ 평균(소수점 첫째 자리) + “(리뷰 N개)” | ★ 평균 + 개수 | ★ 평균 (개수) |
  | 리뷰 0개 | **아직 별점이 없어요** | **아직 별점이 없어요 · 첫 리뷰를 남겨주세요** | **아직 별점이 없어요** |
  | 불러오는 중 | 별점을 불러오는 중이에요… | 같은 문구 | (표시 없음) |
  | 불러오기 실패 | 별점을 불러오지 못했어요 (리뷰 0개와 구분) | 같은 문구 | (표시 없음) |
  평균 5점도 `5.0`처럼 소수점 첫째 자리까지 보여요. 0점/0.0은 어디에도 나오지 않아요.
- **서버 집계를 못 가져왔을 때**: 이미 불러온 리뷰로 대신 계산해요 (최신 500개 + 내 리뷰라서 일부일 수 있어요). 리뷰 목록까지 실패했다면 “리뷰 없음”이 아니라 “불러오지 못했어요”로 보여요.
- **로컬 모드는 그대로**: 별점 집계를 쓰지 않아요 (`status: off`). 카드의 `rating`/예시 리뷰 수 표시와 예전 문구가 그대로예요.
- **반올림**: 서버 `round(avg, 1)`과 화면 계산이 같도록 정수 계산을 써요 (4.25 → 4.3 같은 경계까지 일치).
- 집계가 1000줄을 넘어도 나눠 받아서 일부가 빠지지 않아요.

## 3. 알아둘 점

- 다른 사용자가 새 리뷰를 쓰면, 내 화면에는 **빵집 상세를 열거나 새로고침할 때** 반영돼요 (실시간 푸시는 아니에요).
- 별점 줄의 별 모양은 0.5 단위로 그려지고(예: 4.3 → ★4.5 모양), 숫자는 4.3으로 정확히 보여요.
- 집계는 `ranking_bakeries`(0005)를 읽어요. 그 뷰가 서버에 없으면 별점은 “불러오지 못했어요”로 보여요.

## 4. 실제 브라우저에서 확인하기

1. **새로고침** 후 방금 리뷰를 남긴 빵집의 **상세**: 평균 별점과 “(리뷰 N개)”가 보이는지 (예: 옵스 해운대점 5.0 · 1개, 이흥용과자점 4.0 · 1개)
2. **홈의 같은 빵집 카드 · 지도에서 그 빵집을 눌렀을 때의 미리보기 카드**에 상세와 **같은 숫자**가 보이는지
3. 리뷰가 없는 빵집: 상세 “아직 별점이 없어요”, 카드 “아직 별점이 없어요 · 첫 리뷰를 남겨주세요”, **0.0이 안 보이는지**
4. 별점을 **수정**하고 저장 → 상세로 돌아와 평균이 즉시 바뀌는지 (리뷰 1개면 평균 = 내 별점)
5. 리뷰를 **삭제** → 리뷰 0개면 “아직 별점이 없어요”로 돌아가는지, 새로고침해도 같은지
6. (계정 2개가 있다면) 다른 계정으로 같은 빵집에 별점을 남기고, 첫 번째 계정에서 **상세를 다시 열면** 평균이 (두 별점의 평균, 소수점 첫째 자리)로 바뀌는지
7. 모바일 폭에서 별점 줄이 줄바꿈 없이 보이는지
8. 로컬 모드(`VITE_DATA_BACKEND=local`)에서 예전과 똑같이 보이는지 (선택)

서버 값은 `node supabase/check-live.mjs`로도 확인할 수 있어요 (“빵집 평균 별점 · 리뷰 개수가 reviews 표의 별점과 일치” 항목, 빵집별 점수 출력).
